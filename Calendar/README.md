# Calendar

The time layer: notes anchored to a date rather than a subject. The daily note is the single most important file in this vault, because it is where everything enters. The one habit this system asks of you: open today's daily note and dump everything there. The [[daily-review]] SOP sorts it later.

## Subfolders

| Folder | Holds |
|---|---|
| `Daily Notes/` | One note per day: log, captures, tasks |
| `Weekly Notes/` | One note per week: review and preview |
| `Monthly Notes/` | One note per month: rolls up the weeks, review and preview |
| `Quarterly Notes/` | One note per quarter: rolls up the months, goals and bets |
| `Yearly Notes/` | One note per year: rolls up the quarters, annual review |
| `Meetings/` | One note per meeting, linked to people and projects |
| `Work Sessions/` | One note per focused work block on a project |

## What belongs here

- Periodic notes: `type: daily`, `weekly`, `monthly`, `quarterly`, `yearly` — each altitude rolls up the one below.
- Event notes: `type: meeting` and `type: work-session`, linked to the people and projects they touch.
- Anything time-bound: what happened, what was said, what you thought that day.
- Logs use the `#log/*` taxonomy (see [[tasks-and-logs]]); a log line worth remembering as a decision is tagged `#log/decision` and the weekly/monthly/quarterly/yearly notes roll those up automatically.

## What does not belong here

- Distilled knowledge (promote it to `Atlas/` via [[daily-review]] or [[ingest]]).
- Project plans (those live in `Efforts/` and get linked from daily notes).
