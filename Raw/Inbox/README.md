# Inbox

The analysis queue. Originals land here and wait, in whatever form they arrived: PDFs, slide decks, saved web pages, clippings, and your own long-form writing you want read rather than filed. Any file type belongs here — dumping it is the whole point.

Nothing here is edited. Ingest reads the capture, extracts what matters into `Atlas/`, appends a summary and links to the original, then moves it to `Sources/`. Leaving this folder is what marks a capture processed.

What is still waiting shows up on the [[Inbox|Inbox dashboard]] next to your Fleeting notes.
