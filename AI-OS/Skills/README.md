# Skills

Skills are optional reusable instruction files (`skill-name/SKILL.md`) that teach an AI tool a specific capability. The vault works fully without them. What a skill is, how to install one and which to start with: [[ai-setup#Skills]].

## Installed skills

One row per skill in this folder. The AI adds a row when it installs or writes a skill, and reads this table to know what is available and which SOPs rely on it.

| Skill | Source | Used by |

Source is a URL or "own". Used by names the SOPs or requests that rely on the skill.
