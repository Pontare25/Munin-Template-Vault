# Archive

Closed efforts live here, in folders that mirror where they came from: `Projects/`, `Learning/`, `Areas/` and `Tasks/<year>/`. Status stays the truth (`done` or `dropped`); the folder only keeps them out of the way.

- **When things move:** at the monthly review, projects, learning projects and Areas that have been `done` or `dropped` for a while move here. Move them inside Obsidian (drag in the file explorer, or right-click and Move file to), never in your file manager, so links keep working.
- **Tasks:** archive a task from its card in TaskNotes (right-click, Archive). TaskNotes moves it to `Tasks/<year>/`.
- **What never moves here:** Calendar notes, Atlas notes, fleeting notes and sources.
- **Out of search:** this folder is in Settings, Files and links, Excluded files, so search, the graph and the quick switcher skip it. Links into it still work, and the Archive views below still list it.
